Team Structure

Each fantasy team consists of 7 players in the following slots:

RoleCountNote
Duelist1Must be Duelist
Initiator1Must be Initiator
Controller1Must be Controller
Sentinel1Must be Sentinel
Any3Any of the four roles above

⚠️ Same-team player limit is set per matchday by the admin — see Matchday Rules below

Budget System

Each fantasy team has a 100M budget to pick players

Player prices range from 6M to 25M

Prices change after the admin enters scores, following a per-matchday bands table — see Matchday Rules below

Matchday Rules

Same-team limit, free transfers and price-change bands can all be set per matchday by the admin — no app update needed. "Unlimited" means no cap and, for transfers, no penalty at all that matchday.

Transfer Rules

Each transfer beyond a matchday's free quota costs -8 pts per player, unless that matchday is Unlimited or the Wildcard chip is active.

Swap by position only

A player can only be replaced by a player of the same position — Duelist ↔ Duelist, Initiator ↔ Initiator, Controller ↔ Controller, Sentinel ↔ Sentinel. Any slots can be swapped with any position.

Free transfers do not carry over between Matchdays

⏰ Manage your team until the Deadline before the first match of that Matchday
